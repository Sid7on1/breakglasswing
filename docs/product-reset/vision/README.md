# Owner product vision

This folder preserves the owner's north-star definition of **Bimax Mac Buddy**. Agents working on
the Mac app, adaptive runtime, developer-environment intelligence, performance, computer use, or
Trust Engine must read `BIMAX_MAC_BUDDY_PRODUCT_VISION.md` before planning or changing those areas.

The vision is direction, not an implementation claim. Every delivery still uses the repository's
status vocabulary and must pass `../08_ACCEPTANCE_GATES.md`. Broad ideas should be split into
measurable slices; they must not become speculative complexity on an interactive path.

The supplied source contains duplicate section numbers 27, 28, and 29 because later owner additions
continue from the second section 27 while the original vision already used 28 and 29. That numbering
is intentionally preserved so the owner's text remains verbatim. A future normalized product
specification may renumber it, but must retain a link to this source.

For research and planning, `../12_ALL_VISION_SECTIONS_RESEARCH_PLAYBOOK.md` assigns stable IDs
V01–V34 plus V27B/V28B/V29B and covers all 37 distinct chapters without changing this verbatim file.
