# Examples index

Examples are saved as observations and links, not copied marketing assets. This keeps the research
reviewable without treating another product's screenshots or source as Bimax material.

- `CURRENT_BIMAX_UI.md` audits the existing Bimax screenshots component by component.
- `REFERENCE_MATRIX.md` maps specific reference-product interactions to Bimax decisions.
- `PHASE5_FRONTEND_REFERENCES.md` records the 2026-08-09 first-party interaction/accessibility
  research that drove the frontend reset, and the deterministic artifacts that phase stores.
- `../03_PRODUCT_EXAMPLES.md` contains the full case studies and primary source links.

During frontend implementation, each changed core journey should be reviewed against the relevant
row in `REFERENCE_MATRIX.md`, then judged against Bimax's own acceptance gates—not visual similarity
to the reference product.
