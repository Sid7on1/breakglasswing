## What was rejected, and why

- **Temporal/OpenHands as dependencies** — both are servers/frameworks; BiMax needs the *pattern*
  (typed log + fold), not a runtime dependency. No code was vendored from either.
- **SQLite for the execution ledger** — the mind layer already uses SQLite (`.bimax/ledger.db`),
  but the execution journal must stay human-inspectable and corruption-tolerant line-by-line
  (a half-written NDJSON line loses one record; a half-written SQLite page can lose the file
  without WAL discipline). NDJSON + atomic rewrite chosen.
- **Faking pause for non-process tasks** (some task managers mark anything "paused") — rejected
  per mandate §6; pause exists only where SIGSTOP is real.
